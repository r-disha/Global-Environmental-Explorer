# Global Environmental Explorer

An interactive Streamlit web application that provides real-time Air Quality Index (AQI), weather, and traffic conditions for cities worldwide, visualized on an interactive 3D globe.

## Features
- **Real-Time Data:** Fetches AQI, temperature, weather conditions, and traffic status.
- **Interactive 3D Globe:** Visualizes the selected city on a high-resolution, interactive 3D Earth using Plotly.
- **Graceful Fallbacks:** Seamlessly falls back to mock data when API limits are reached, ensuring a continuous user experience.

## Installation

1. Clone the repository:
   ```bash
   git clone <your-repository-url>
   cd POLUTIONDETECTION
   ```

2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```

## Usage

Run the Streamlit application:
```bash
streamlit run app.py
```
